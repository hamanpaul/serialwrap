Rust 0.5.1（BC-23）為 Windows TCP console 的 raw owner 在 session lease 層補上 lifetime 鏡像，使 `self-test`、reprobe 與 agent interactive 仲裁能看見 TCP human。EOF 僅撤除對應 client lifetime 的鏡像；A 斷線後 B 接手時，不會清除 B 的 raw owner。閒置 human 可被 agent soft preempt；close／expiry 沿既有 `execute_post_close`／`resume_human` 恢復 raw ownership，再由同步路徑依現況建立 mirror。明確的 `session.interactive_close` 關閉仍登記 TCP client 的 human lease（不論是 mirror 或普通 lease）後，同步不會立即補回 mirror。self-heal、retained／stash 還原與 `interactive_open` 等既有授權路徑重新授予該 client 時，會以目前 console lifetime 清除撤權，並維持各路徑修前的 Lease／LeaseIndex 記法；`interactive_open` 的普通 human lease 仍是 `Insert`，不帶 `mirror_client_lifetime`。`console_detach`、EOF、stale prune 與 release close-all 在 lifetime 離開 `human.consoles` 時立即清除撤權，不必等待 EOF。撤權只影響 Lease／LeaseIndex 簿記，不改 raw ownership、admission、suspend／resume、deferred input、回放或 raw／line 輸入路由。flash、handoff、release 等 guard 關閉期間不建立、不回放、不提升 TCP mirror lease，既有 mirror 簿記由同步路徑撤除；其他 raw 行為維持修前 Rust 基線。guard 開放至下一次同步之間，TCP human 可能暫時沒有 mirror lease，agent command 依既有仲裁執行。PTY 與 Python 語意不變。活躍 human 維持 `SESSION_INTERACTIVE_BUSY`。鏡像只記於內部 LeaseIndex，不產生 handoff 的 `AdmissionFlag::Lease`。已有 human lease 時，預設 line mode 的 bare `--source human` `command.submit` 在執行 gate 終結為 `SESSION_INTERACTIVE_BUSY` 且零 UART TX。`file.push`／`file.pull` 保留 agent 執行政策與既有傳輸 gate。Linux native TCP + fake UART/WAL 覆蓋本次接線；Windows 原生與 Tera Term smoke 待另行驗證。
