### 6eafa6a feat(rust-console): interactive lease 承接 human lease、stash 與可重複讀 tombstone

1. **[High] [crates/sw-core/src/session_core/lease_p6.rs:139](crates/sw-core/src/session_core/lease_p6.rs:139) — 命令出列時的 lazy expiry 仍會撤銷剛建立的回放。**

   具體輸入：human `c1` 被 agent lease A soft-preempt，鍵入 `Q`；A 到期但尚未處理 Tick，接著提交 `echo B`。

   `execute_time_reject()` 的 refresh 會還原 human 並建立回放 hold，但 `start_next()` 只在進入時檢查 hold，之後直接啟動 B。`command_fg_begin()` 因而撤銷剛建立的回放，UART 順序變成 **B → Q**；若 B 是 reboot，`Q` 會被失效丟棄。Python `execute_command()` 在執行命令前同步執行 `post.execute()`，順序應為 **Q → B**。

   **確切修法：**在 queue pop／`mark_running` 前完成 refresh，再檢查 hold；有回放時保留 B，待回放結算後重新評估。新增「lazy expiry＋下一條一般命令／reboot」回歸，鎖住 UART 順序及不得遺失 `Q`。

### 17270a4 test(p6): Task 9 ConsoleHub runtime 與 RX fan-out 的失敗測試

2. **[Medium] [crates/sw-core/tests/console_echo_latency.rs:30](crates/sw-core/tests/console_echo_latency.rs:30) — loopback 延遲測試可把本地回顯當成 DUT 回顯。**

   測試只等待 `c1.written()` 出現按鍵，沒有確認按鍵經 UART TX、DUT loopback RX 返回。若 raw ownership 回歸成 line mode，line editor 仍會立即回顯這 500 個字元；沒有換行，UART 可以完全沒有收到資料，測試仍能取得漂亮的 p99。

   **確切修法：**先斷言 raw owner；每筆樣本須確認對應 UART TX 與 loopback RX，再接受 console 回顯。補上強制改走 line mode 的負對照，確認測試會紅，避免量到本地回顯延遲。

### 4f710c3 feat(rust-console): 新增不阻塞的 ConsoleHub thread、RX fan-out 與 peer 掃描

3. **[High] [crates/sw-core/src/human_console/hub.rs:503](crates/sw-core/src/human_console/hub.rs:503) — release 後，晚到的 `ConsoleConnected` 可復活已關閉的 console。**

   具體順序：TCP accept 已產生 `ConsoleConnected`，但事件仍在 hub pending 或 actor control lane；`device.release` 經 safety lane 先完成 Phase 1，清空 core console。Hub 隨後 `close_everything()` 關閉 socket，卻保留 pending 事件，而且關閉不送 disconnected。

   晚到事件進入 `console_connected()` 時沒有 bridge 世代或狀態檢查，會重新登記 client、設 `peer_present=true` 並授予 raw owner。結果是 **RELEASED session 再次出現已關閉的 console**；後續 reclaim 也可能沿用這個幽靈 owner，使新連線無法取得正常 raw 操作。正確結果應維持 `console_count=0`、無 owner。

   **確切修法：**`ConsoleConnected` 帶 listener／bridge generation；core 拒絕已失效世代並要求關閉 client。Close-all 同時撤銷尚未登記的 accept，不能只清 hub pending，因為事件可能已進 mailbox。新增 release 超越待處理連線事件、再 reclaim 的決定性回歸。
