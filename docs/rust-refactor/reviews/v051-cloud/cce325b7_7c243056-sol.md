1. **V051-7c24305-1 [High]** [deferred.rs:175](crates/sw-core/src/deferred.rs:175) — **deferred 合併同判定的輸入後，行尾後被判為 secret 的 bytes 會明文寫入 TX WAL。**例如窗口 active、human 輸入被 suspend 而進 deferred 時，actor 先後接收 `abc\r`、`def`；因 writer 尚未送出換行，兩筆取得相同的 active 快照，卻被合併為一個 `abc\rdef` replay。writer 的 [with_human_tx_window_snapshot](crates/sw-core/src/uart_bridge.rs:384) 只把第一個行尾之前的 `abc` 視為 secret，[TX WAL](crates/sw-core/src/tx_writer.rs:1269) 因而記錄 `\rdef`；`def` 也未登記供回顯遮罩。這違反每筆輸入的接收時判定須一路傳至 WAL、META 與 echo 登記的裁決，也使 C 第 1、4 項尚未完成。此反例是依控制流靜態推導，未新增或修改測試實跑。
