### V051-438c03d-3 [Medium] 標為 core portable 的 fallback 測試依賴 Unix shell

[fallback 測試](tests/test_docker_upgrade.py:1513) 標為 `core_portable`，卻建立 `#!/bin/sh` 腳本並執行 `/usr/bin/python3`。Windows 原生執行時無法以這種方式啟動候選直譯器，parser attempt 會是 `unavailable`，但測試要求 `missing_pyyaml`，因此該必要節點會失敗。

在 Linux 以記憶體替身模擬「無法執行該 POSIX 腳本」後，該節點實測 **1 failed**，實際 `unavailable`、預期 `missing_pyyaml`；這不是 Windows 原生實跑證據。

**修法：**使用跨平台的受控 subprocess 替身或可攜直譯器配置，明確模擬候選直譯器缺 PyYAML，同時保留 fallback 路徑、版本與兩次 attempt 的斷言；維持 `core_portable` 分母。
