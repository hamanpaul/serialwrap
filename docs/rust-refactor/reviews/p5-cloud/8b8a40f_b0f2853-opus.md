   - 如果 `release_block()` 剛好落在這個空窗，放行旗標會被清掉，writer 就永遠阻塞。drain timer 綁 FakeClock，沒人推進就不會到期。
   - 實測：binary 6 個並行跑 10 輪，`actor_answers_get_state_while_drain_pending` 有 1 次在 `:98` 失敗，訊息是 `recv_timeout ... Err(Timeout)`。這和 commit 說的「200 次＋180 次全過」不一致，而這個 nodeid 已經進了 L1 鎖。
