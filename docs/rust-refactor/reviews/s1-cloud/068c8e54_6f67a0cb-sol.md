- 實際：刪除的是尚不存在的 `/home/alice/.config/systemd/user/.../90-serialwrap-update-hold.conf`。XDG 那份 drop-in 仍在，systemd 仍回報 `Restart=no`、`RefuseManualStart=yes`。`release_named` 回 `systemd hold 撤銷驗證不符`，恢復停在 `autostart_release_failed`。
