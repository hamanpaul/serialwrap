## B 新發現

### P7-71fe017-1

**[Medium] `crates/sw-pal/src/process/handler_posix.rs:183` — timeout 溢位後提前關閉管線，改變 handler 行為。**

`f150a24` 新增的分支立即關閉 stdin／stdout／stderr。具體輸入為巨大 `timeout_ms`，handler 執行 `python3 -c 'import sys; sys.stdin.buffer.read()'`：Python 3.12.3 探針確認，溢位及呼叫框架釋放後，`subprocess._active` 仍保留 Popen，三條管線保持開啟，子程序持續等待；Rust 此處則送出 stdin EOF，使子程序結束。會寫 stdout 的 handler 也可能因此遇到斷管。

**確切修法：**保留管線所有權，將完整 Child 移交背景回收路徑，待子程序結束後才關閉；新增「巨大 timeout 後等待 stdin 的 handler 不提前收到 EOF」測試。原 finding 1 的名額流失已修，本項是修法新增的行為差異。
