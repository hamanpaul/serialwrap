1. [Medium] `crates/sw-core/src/session_manager.rs:2547`、`:1946`

     - RPC thread 逾時後會刪掉暫存的 `PtyPair`，但 request 已經進了 actor。core 之後照樣插入 console、開 `human:<cid>` lease、發 `LeaseIndex::Insert`。executor 在 `ConsoleAdopt` 取不到 pair，就靜默略過。
