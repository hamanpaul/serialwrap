# serialwrap v0.2.0

## Highlights

- **安裝流程重構為 pipx + systemd**（`feature/install-flow-systemd-pipx`，PR #74）：`pyproject.toml` 打包、`serialwrap setup` / `doctor` / `service` 子命令、`supervision_mode` 單一事實來源、XDG 路徑、無 systemd 自動降級 on-demand。
- **MCU 韌體升級 flash 端點 `/dev/ttyMCU`（#55）**：daemon 維持 tty 唯一 reader 下提供 byte-transparent flash broker，sync-probe 自動認線、FLASHING 仲裁；真機 gate 已通過（`Return error code : 0x0`）。
- **device release / attach handoff（#54）**：daemon 持續運作下把單一 UART 乾淨交給外部 flasher 再收回（新增 `RELEASED` 狀態）。
- **bulk 傳檔不再凍結共用 daemon 的所有 RPC（#52）**、**開機窗自動重探（#69）**、**command_capable 判準（#51）**、**閒置 human lease soft preempt（#53）**。
- 退役 vestigial MCP 層（#59）；升級 policy conventions v1.0.5。
- **agent 檔改為單一事實來源**：`AGENTS.md` / `GEMINI.md` / `.github/copilot-instructions.md` 改為指向 `CLAUDE.md` 的 symlink，往後只維護 `CLAUDE.md`。
