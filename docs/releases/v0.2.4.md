# serialwrap v0.2.4

本版收斂 v0.2.3 起累積的三項工作：新增 `serialwrap remote`（按需 SSH 反向隧道，讓遠端 agent 取得本機 serialwrap 操作）、U-Boot autoboot 倒數窗的 recovery lease 擴充（#114）、實機穩定性測試套件 `python3 -m realhw`（#122），以及登入帳密解析為空時的明確終態修復（#140）。daemon 零改動，Windows 端行為除 `serialwrap remote`（僅 POSIX，native Windows 回 `REMOTE_NOT_SUPPORTED`）外不受影響。

## Highlights

- **`serialwrap remote`：按需開關 SSH 反向隧道**：`-R` expose（預設）／`-L` connect 兩種模式，讓遠端 agent 取得本機 serialwrap 操作；background 常駐、flock registry、readiness 確認、`--remote-socket` 硬化、fail-closed 遠端 bind 驗證（`ss` 綁定檢查改 loopback allowlist，杜絕介面 IP／global v6 誤判安全）。daemon 本身零改動、不做預設啟用、僅 POSIX（native Windows 一律回 `REMOTE_NOT_SUPPORTED`，`_run_remote` 於 `import remote_tunnel` 之前即攔截，`status`／`close`／open 三條路徑一致）。docker 三拓樸（direct／NAT→host／NAT←client）驗收，含獨立攻擊者容器驗證同網段真連不到 relay 非 loopback 位址。
- **U-Boot autoboot 倒數窗 recovery lease（#114）**：`interactive-open --allow-attached` 的 recovery lease 授予條件擴充至 autoboot 倒數窗——RX tail 命中 boot banner（複用 #130 `detect_boot_banner`）即授予 lease 並帶 `boot_interrupt: true`，可在板子 autoboot 載入壞 image 前搶開 lease 中斷倒數、逐字驅動 U-Boot 救 fw，不必等它先停在 bootloader prompt。
- **實機穩定性測試套件 `python3 -m realhw`（#122）**：P0 煙躖×8＋P1 核心穩定性×20（console 對抗／重啟恢復／裝置交接／usbipd 插拔／命令執行／WAL）全自動、長跑（`lr-mixed`，預設 32h）無人看護＋事後分析報告；preflight 守門（部署新鮮度／doctor／兩板 READY／工具可用／環境乾淨／破壞性預告，任一不過整場拒跑）。測部署後系統，不進 CI、不入 wheel。
- **`CREDENTIALS_UNRESOLVED` 明確終態（#140）**：帳密宣告但解析為空時不再靜默送空帳密狂 probe——`resolve_session_auth()` 新增 `AuthResolution.reason`（`ok`／`env_file_missing`／`env_file_unreadable`／`key_absent`／`not_configured`），profile 宣告帳密來源但解析為空時 session 標 `CREDENTIALS_UNRESOLVED` 並停止自動 reprobe，與「板子尚未到 login prompt」的 `LOGIN_REQUIRED` 明確區分；四條 attach/recover 路徑一致套用，daemon 輸出一次性警告（含 env_file 解析絕對路徑，絕不含帳密值）。
